# Code of conduct

We welcome people with different backgrounds and experience. Treat participants
with respect, focus criticism on code and claims, and allow questions and corrections.
Harassment, threats, discriminatory abuse, sexual harassment, doxxing and repeated
unwanted contact are unacceptable. Do not share others' private information.
These expectations cover project issues, discussions, reviews and project-related
community interactions. Each host community's own rules also apply.

The repository maintainer moderates project spaces and can edit/remove harmful
content, warn participants, restrict participation or ban repeat/severe offenders.
Actions should be proportionate and communicated when practical. The project
currently has one maintainer; there is no independent conduct committee.

For harmful content, use GitHub's built-in report/block mechanisms or the host
community's moderation channel. To request a private conversation with the
maintainer, ask for a private channel without posting incident details; no
project-specific confidential inbox is currently configured. If the maintainer
is involved, use the platform's reporting mechanism. Keep private evidence out
of public issues. Security vulnerabilities follow SECURITY.md instead.
